# OI Digitals

Public site for **OI Digitals** — software house (software, AI, apps, design).

- Site: planned domain **oidigitals.net**
- Work (send this to customers): `/work`
- Print / PDF: `/work/print` → `public/oi-digitals-work.pdf`
- Client privacy: `/privacy`

Own products are named. Client work is described without company names.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## PDF

With the dev server running:

```bash
npm run pdf
```

Writes `public/oi-digitals-work.pdf`.

## Deploy

Import this repo in [Vercel](https://vercel.com/new). After you buy `oidigitals.net`, add the domain in Vercel and point DNS.

Email on the site is `hello@oidigitals.net` — create that mailbox when the domain is live.
